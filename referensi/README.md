# Referensi Visual Pockito

Folder ini untuk menyimpan screenshot, mockup, dan gambar referensi UI/UX yang ingin dipakai saat mengembangkan Pockito.

## Cara memakai

1. Buka folder yang sesuai.
2. Klik **Add file → Upload files** di GitHub.
3. Unggah gambar referensi (PNG, JPG, atau WEBP).
4. Beri nama file yang mudah dicari, misalnya `cicilan-ringkasan-mobile.png`.
5. Saat meminta perubahan ke ChatGPT/Codex, sebutkan nama file atau tautan GitHub-nya.

## Kategori

- `kredit/` — referensi akun kredit, PayLater, kartu kredit, dan utang.
- `cicilan/` — referensi jadwal cicilan, pembayaran, dan tagihan.
- `dashboard/` — referensi ringkasan, statistik, dan tampilan utama.
- `lainnya/` — ide visual yang belum masuk kategori.

**Catatan:** gambar di sini hanya referensi. Jangan unggah screenshot yang memuat kata sandi, token, data rekening sensitif, atau informasi pribadi orang lain.
